# ADR 0041 — Un classeur de signes, des signes lus dès qu'ils sont finis

- **Date** : 2026-11-08 · **Statut** : accepté · Suite de l'ADR 0038, idée de Mikajy (https://github.com/ARHeritiana/Mikajy).
- **Contexte** : la lecture au tracé (ADR 0035, 0037) appelait directement les gabarits $P à la pause, pour chaque signe ; le petit modèle par signe (ADR 0038) doit pouvoir les remplacer sans toucher aux règles de la ligne.
- **Décision** : une interface `ClasseurSignes` (`app/lib/reconnaissance/classeur_signes.dart`) : `classer` (asynchrone, meilleures classes et probabilités) et des verdicts immédiats avec les règles de doute (`signe`, `chiffre`, `capitale`, `impose`). `ClasseurGabarits` = les gabarits tels quels ; `ClasseurAppris` = corrections de la personne, puis le modèle s'il est là, sinon les gabarits, avec un cache par signe. `trace_ligne.dart` et `structure.dart` le demandent à `classeurCourant` (zone Dart) : sans lui, rien ne change.
- **Lecture continue** : 250 ms sans nouveau trait, les signes nouveaux sont classés ; si chaque ligne se lit déjà au tracé, la pause passe de 700 à 400 ms. Le journal `fikajiana.lecture` donne le temps de chaque voie (structure, tracé, Pix2Text).
- **Correction** : sur une ligne lue au tracé, le panneau Corriger montre ses signes ; en toucher un propose ses 3 meilleures classes. Le choix relit la ligne et reste sur l'appareil (`signes/exemples.json`), jamais envoyé ; un plus proche voisin sur ces exemples passe avant tout quand il est sûr (distance ≤ 0,5, autre classe à ≥ 0,25 de plus). « Exporter mes corrections » (Réglages) écrit le format de `collecte/FORMAT.md`, en CC0.
- **Modèle** (contrat v1, ADR 0040) : `ClasseurOnnx` rend l'image en Dart pur comme `rendu.py` (écart moyen 0,0001 par pixel sur 138 signes, `rendu_signe_test`), charge `assets/modeles/` s'il y est. Les gabarits d'abord ; le modèle répond quand ils doutent, à p ≥ 0,7 et 0,3 d'écart au second, réglé sur les séances jamais vues (18 pris sur 33 doutes, tous justes). Pad 7 : 3,6 ms par signe, 36/45 justes sur les séances jamais vues ; aucune ligne des fixtures ne change (leurs échecs sont de structure). Poids hors Git tant qu'une version n'est pas adoptée.
- **Mesure** (Pad 7, `tool/banc/lancer.sh android-arm64 banc/banc_lecture.dart`) : ligne simple au tracé 9 à 23 ms avant, 0,1 à 0,2 ms après (signes déjà classés), 6/6 sous le budget de 50 ms.
